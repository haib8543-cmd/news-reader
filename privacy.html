개인정보처리방침

시행일: 2026년 10월 27일 · 운영: 박일성

법률 검토 필요: 이 방침은 개인정보 보호법 제30조의 기재 사항을 기준으로 작성한 초안입니다. 운영 주체(개인·사업자), 위탁·국외 이전 사항, 보유 기간을 실제 계약과 설정에 맞춰 전문가 검토를 받은 뒤 확정하세요.

1. 한눈에 보기

  • 회원가입이 없고, 이름·이메일·전화번호를 받지 않습니다.
  • ‘내 데이터 분석하기’에 넣은 파일과 글은 이용자의 브라우저 안에서만 처리하며 서버로 보내지 않습니다.
  • YouTube 링크 기능은 영상 ID를 분석 서버로 보내 공식 YouTube Data API로 조회합니다. 댓글 원문은 저장하지 않습니다.
  • 요청 횟수 제한을 위해 접속 IP를 되돌릴 수 없는 값(HMAC 해시)으로 바꿔 서버 메모리에 최대 하루 둡니다.

3. YouTube API 서비스 이용

이 사이트는 YouTube API 서비스를 사용합니다. YouTube 기능을 이용하면 YouTube 서비스 약관에 동의하는 것으로 보며, Google이 처리하는 정보는 Google 개인정보처리방침을 따릅니다.

  • 이 사이트는 이용자의 Google 계정에 접근하지 않습니다(로그인·OAuth 권한 요청 없음). 따라서 Google 보안 설정 페이지에서 철회할 권한도 없습니다.
  • YouTube에서 받은 정보는 위 표의 기간 안에서만 다루고 제3자에게 제공하거나 판매하지 않습니다.
  • 이 사이트는 YouTube 기능을 위해 쿠키를 저장하거나 읽지 않습니다. 영상 썸네일 이미지는 YouTube 이미지 서버(i.ytimg.com)에서 이용자의 브라우저로 직접 불러오며, 이때 YouTube 서버가 접속 정보를 받을 수 있습니다.

5. 방문 통계와 광고

Cloudflare Web Analytics로 방문 수와 많이 본 페이지를 셉니다. 쿠키를 쓰지 않고 개인을 식별하지 않으며, 집계된 수치만 남습니다.

현재 광고를 싣지 않습니다. 광고를 켜면 광고 사업자(예: Google AdSense, 카카오 애드핏)가 쿠키 등으로 정보를 수집할 수 있으며, 그 전에 이 항목을 갱신합니다.

6. 이용자의 권리

이용자는 개인정보 열람·정정·삭제·처리정지를 요구할 수 있습니다. 이 사이트는 개인을 식별하는 정보를 저장하지 않아 대부분 해당 정보가 없지만, 요청은 문의·삭제 요청 페이지의 방법으로 받습니다. 브라우저 저장소의 설정 값은 브라우저의 사이트 데이터 삭제로 직접 지울 수 있습니다.

7. 안전성 확보 조치

  • 모든 통신은 HTTPS로만 받습니다. 서버는 허용한 사이트 주소에서 온 요청만 받습니다(CORS).
  • API 키는 서버 환경 변수에만 두고 사이트 코드에 넣지 않습니다.
  • 요청 크기·시간·횟수를 제한하고, 오류 응답에 내부 정보를 담지 않습니다.
  • 콘텐츠 보안 정책(CSP)으로 허용한 출처의 스크립트만 실행합니다.
