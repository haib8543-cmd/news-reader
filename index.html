          이 비교가 하지 못하는 것

          1. 최근 24시간 영상(채널당 최소 15개, 너무 많으면 조회수 상위 200개)만 봅니다. 그날 큰 사건에 따라 결과가 크게 바뀌고, 방송사 전체의 성향을 판정하지 않습니다.
          2. 단어 사전으로 찾습니다. 반어, 맥락, 화면 속 내용은 보지 못합니다. 근거 영상을 직접 열어 확인하세요.
          3. 무엇을 보도하지 않았는지(의제 누락)는 세지 못합니다.
          4. 판결·체포 같은 사실을 전한 것은 묘사어로 세지 않습니다. 인물을 꾸미는 말과 평가하는 말만 셉니다.
          5. 사실 여부는 판정하지 않습니다. 사실 확인은 원문 기사와 공신력 있는 자료로 하세요.

          인물·정당 사전

          01 / SOURCE DATA

          분석할 데이터

          watch, youtu.be, shorts, live, 모바일(m.youtube.com) 링크를 넣을 수 있습니다.

          댓글 통계 분석은 준비 중입니다. YouTube API 정책상 댓글로 새로운 지표를 계산하는 기능은 운영자가 YouTube의 승인을 확인한 뒤 엽니다. 지금은 영상 기본 정보만 확인할 수 있고, 오른쪽 결과는 가상의 데모 데이터입니다.

          영상 정보는 공식 YouTube Data API로 조회합니다. 링크를 넣고 처음 확인할 때 데이터 처리 안내에 동의를 받습니다. 개인정보처리방침

          직접 가진 텍스트 데이터(설문 응답, 내가 운영하는 게시판의 글 등)를 이 브라우저 안에서만 분석합니다. 서버로 보내지 않고, 페이지를 닫거나 ‘데이터 지우기’를 누르면 사라집니다.

          데이터 출처 (필수)

          CSV는 text(또는 comment, 내용) 열과 선택 사항인 time(또는 publishedAt, 작성시각) 열을 읽습니다. 작성자 열이 있어도 읽지 않습니다. 이 기능에는 표현 유형 분석이 없습니다(그 사전은 서버에만 있습니다).

          1. 무엇을 보여 주나요

            댓글을 한 건씩 판정하지 않고, 같은 문장·비슷한 문장이 얼마나 되는지, 언제 몰렸는지를 묶음 단위 통계로 보여 줍니다.

          2. 왜 10건 기준인가요

            작은 묶음은 특정인을 짐작하게 할 수 있어 10건 미만인 묶음과 시간 구간은 숫자를 숨기거나 더 큰 구간으로 합칩니다.

          3. 반복이 많으면 조작인가요

            아닙니다. 같은 구호를 함께 쓰는 응원, 인기 있는 짧은 반응도 반복으로 잡힙니다. 이 도구는 그런 판단을 하지 않습니다.

          4. 표현 유형은 무엇인가요

            공유 요청, 단정, 비하처럼 표현의 종류를 단어 사전으로 센 비율입니다. 누가 썼는지나 정치 성향은 보지 않습니다.

            02 / AGGREGATE STATISTICS

            집계 통계

            모든 그래프는 묶음 단위 숫자입니다. 10건 미만인 칸은 ‘숨김’으로 표시하고 그리지 않습니다. 그래프마다 아래 ‘표로 보기’에서 같은 숫자를 확인할 수 있습니다.

            03 / GROUP NETWORK

            묶음 관계도

            드래그로 회전, 휠·두 손가락으로 확대, 점을 눌러 선택합니다. 화면이 작거나 3D를 쓸 수 없으면 2D로 그립니다.

            04 / METHODOLOGY

            계산 방법과 한계

            어떻게 계산하나
            단계방법
            정리유니코드 표준형(NFKC)으로 바꾸고, 보이지 않는 문자를 지운 뒤, 비교할 때는 글자와 숫자만 남깁니다. 띄어쓰기·문장부호·전각 문자 차이는 같은 것으로 봅니다.
            짧은 반응정리한 뒤 6글자 미만이면(ㅋㅋㅋ, 좋아요 등) 짧은 반응으로 따로 세고 반복 비교에서 뺍니다.
            같은 문장정리한 문장이 글자 하나까지 같으면 ‘같은 문장’입니다.
            비슷한 문장세 글자씩 끊은 조각의 겹침 비율(자카드 유사도)이 0.6 이상이면 ‘비슷한 문장’입니다. 많은 댓글을 빨리 비교하려고 MinHash(48개 해시, 12묶음×4줄)로 후보를 고른 뒤 실제 유사도를 계산합니다.
            묶음같거나 비슷한 문장끼리 이어진 덩어리를 하나의 묶음으로 봅니다. 10건 이상인 묶음만 따로 보여 줍니다.
            시간 분포한국 시간 기준으로 셉니다. 숨겨지는 칸이 30%를 넘으면 1시간→3시간→6시간, 하루→일주일 단위로 합칩니다. 기간은 날짜까지만 표시합니다.
            표현 유형서버에 있는 단어 사전으로 공유 요청, 단정, 비하 등 표현의 종류를 셉니다. 한 댓글이 여러 유형에 들어갈 수 있고, 10건 미만인 유형은 합쳐서 보여 줍니다.
            관계도점은 10건 이상 모인 그룹(반복 묶음, 시간대, 표현 유형)이고, 선은 두 그룹에 함께 속한 댓글이 10건 이상일 때 그립니다. 굵기는 작은 쪽 그룹 가운데 겹치는 비율입니다.

            이 분석이 하지 않는 것

            1. 작성자를 판정하지 않습니다. 이름·채널·프로필은 받지도 보여 주지도 않습니다.
            2. 정치 성향이나 여론 조작 여부를 판단하지 않습니다. 반복이 많다는 것은 관찰 결과일 뿐입니다.
            3. 뜻은 같지만 다른 말로 쓴 문장은 비슷한 문장으로 잡지 못합니다.
            4. 반어·인용·풍자는 구분하지 못할 수 있습니다.
            5. 최신 댓글부터 정해진 수만큼만 봅니다. 영상 전체 댓글이 아닐 수 있으니 결과 위의 표본 정보를 확인하세요.

            데이터 처리

            1. YouTube 링크 분석: 서버가 공식 API로 댓글 본문과 작성 시각만 받아 메모리에서 계산하고, 응답을 보낸 즉시 버립니다. 원문은 저장하지 않습니다.
            2. 내 데이터 분석하기: 이 브라우저 안의 작업 스레드(Web Worker)에서 계산합니다. 서버로 보내지 않고 저장하지 않습니다.
            3. 데모 결과: 운영자가 만든 가상의 문장으로 계산한 예시입니다. 실제 댓글이 아닙니다.

            YouTube 링크를 확인하기 전에

            • 링크에서 영상 ID만 골라 이 사이트의 분석 서버로 보냅니다. 서버는 공식 YouTube Data API로 영상 정보를 조회합니다.
            • 댓글 통계 분석이 열려 있으면 공개 댓글의 본문과 작성 시각만 받아 메모리에서 계산하고, 결과를 보낸 즉시 버립니다. 작성자 이름·채널·프로필 사진은 요청하지 않습니다.
            • 요청 횟수를 제한하려고 접속 주소(IP)를 되돌릴 수 없게 바꾼 값을 서버 메모리에 잠시 둡니다. 접속 기록에는 IP를 남기지 않습니다.
            • 이 기능은 YouTube API 서비스를 사용합니다. 이용하면 YouTube 서비스 약관에 동의하는 것으로 보며, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.
