서비스 소개

운영: 박일성 · 사이트: https://studio365c.com

Studio 36.5 °C의 ‘뉴스/댓글 판독기’는 미디어 데이터를 숫자로 정리해 판단의 근거를 찾도록 돕는 도구입니다. 결과는 단서일 뿐 결론이 아닙니다. 기술로 정리하고, 판단은 사람이 합니다.

두 가지 도구

  1. 방송사 보도 비교 — 국내 방송사 유튜브 뉴스 채널이 공개 RSS로 내보내는 최근 영상 정보를 1시간마다 모아, 의제 구성과 인물·정당을 꾸미는 표현(묘사어), 자극적 제목의 비율을 채널끼리 비교합니다. 영상 제목·설명 원문은 사이트에 저장하지 않습니다.
  2. 댓글 집계 통계 — 댓글을 한 건씩 판정하지 않고, 같은 문장과 비슷한 문장의 비율, 작성 시간 분포, 표현 유형의 비율을 10건 이상 모인 묶음 단위로 보여 줍니다. 작성자는 보지도 보여 주지도 않습니다.

지금 쓸 수 있는 기능

기능상태
방송사 보도 비교 (공개 RSS)운영 중
YouTube 링크로 영상 기본 정보 확인 (공식 API)분석 서버: 아직 연결되지 않음
YouTube 댓글 집계 통계 (공식 API)준비 중 — YouTube 정책 승인 확인 뒤 운영자가 엽니다
내 데이터 분석하기 (브라우저 안에서만)운영 중
데모 결과가상 문장으로 만든 예시, 항상 ‘데모’로 표시

하지 않는 것

  • 특정 댓글 작성자를 ‘봇’, ‘조작 계정’, 특정 정치 성향으로 판정하지 않습니다.
  • 정치적 성향이나 여론 조작 여부를 단정하지 않습니다.
  • 비공식 수집(스크래핑)이나 브라우저 제한 우회로 데이터를 모으지 않습니다.
  • 댓글 원문을 저장하지 않습니다.

YouTube와의 관계

이 사이트는 YouTube API 서비스와 YouTube 공개 RSS를 사용하지만 YouTube·Google이 만들거나 보증한 서비스가 아닙니다. YouTube 기능을 이용하면 YouTube 서비스 약관이 적용되고, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.
